  KEY FINDINGS:
  -----------------------------------------------------------------------

  [PASSED] Access Control
    All 29 protected API routes correctly reject unauthenticated
    requests with 401 Unauthorized. No broken access control was found.

  [PASSED] Injection Defense
    SQL Injection, Cross-Site Scripting (XSS), and malformed JSON
    payloads were all safely handled. The application uses Supabase SDK
    (preventing raw SQL), React JSX auto-escaping (preventing XSS),
    and a global error handler (preventing stack trace leaks).

  [PASSED] Security Headers (API Routes)
    Helmet correctly sets Content-Security-Policy, X-Frame-Options,
    X-Content-Type-Options, and removes X-Powered-By on all API routes.

  [PASSED] Webhook Authentication
    The scan-completed webhook rejects requests with missing or
    invalid X-Scan-Runner-Token headers.

  [PASSED] Production Scan (OWASP ZAP)
    Zero high-severity vulnerabilities found in production. No SQL
    Injection, XSS, Path Traversal, or Broken Access Control detected.
    The Path Traversal false positive from local testing was confirmed
    absent in the production environment.

  ITEMS REQUIRING ACTION:
  -----------------------------------------------------------------------

  1. [CRITICAL] Rate Limiter Misconfiguration
     File: backend/middleware/rateLimiter.js
     The loginLimiter max value is set to 500 instead of the intended
     10 attempts per 15-minute window. This effectively disables brute-
     force protection. The refreshLimiter (1000) and globalLimiter
     (5000) are similarly over-provisioned.
     Fix: Change max values to 10, 30, and 300 respectively.

  2. [HIGH] Dependency Vulnerabilities
     npm audit reports 8 vulnerabilities (5 high, 2 moderate, 1 low)
     across packages including lodash, express-rate-limit, and
     path-to-regexp.
     Fix: Run npm audit fix in the backend directory.

  3. [HIGH] Hardcoded URL
     File: backend/test-pi-signing.js (Line 51)
     A hardcoded Tailscale/mothership URL is embedded in the source.
     Fix: Replace with process.env.FASTAPI_BASE_URL.

  4. [MEDIUM] Missing Security Headers on Static Files (Railway)
     Static files (index.html, robots.txt, sitemap.xml, CSS, SVG)
     served by express.static() do not include CSP, X-Frame-Options,
     X-Content-Type-Options, or HSTS headers.
     Fix: Ensure app.use(helmet()) is placed BEFORE app.use(express.
     static()) in server.js.

  5. [LOW] Cache-Control Directives (Railway)
     Static HTML responses do not set proper cache-control headers.
     Fix: Add cache-control headers for static assets in the Express
     static middleware configuration.
